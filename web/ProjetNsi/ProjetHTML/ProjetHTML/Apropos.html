Description du site

Le site de Smartlife a ete conçu dans le but d'aider toute personne en difficulte de gestion (vie professionnelle et personnelle) dans le but d'organiser ses projets et son avenir, base sur le langage HTML, CSS pour le style et JavaScript pour la logique.

  • HTML : la structure des pages
  • CSS : le style et les couleurs
  • JavaScript : le fonctionnement des outils
